<h1>Landing Page de Streaming</h1>
<p>
  This README is also available in <a href="./README.md">English</a>.
</p>
<p>
  Uma landing page responsiva inspirada em <i>Gato de Botas 2: O Último Pedido</i>, desenvolvida para praticar
  <strong>Gulp</strong>, <strong>SASS/SCSS</strong> e fluxos de trabalho frontend.
  Demonstra otimização de assets, SCSS modular, interatividade no FAQ e comportamento dinâmico do cabeçalho.
</p>
<h2>🚀 Funcionalidades</h2>
<ul>
  <li>Layout responsivo construído com HTML5, SCSS e mixins modulares;</li>
  <li>Seção de FAQ interativa com abertura/fechamento suave;</li>
  <li>Cabeçalho dinâmico que esconde e reaparece de acordo com a rolagem;</li>
  <li>Otimização de assets (imagens, estilos, scripts) utilizando plugins do Gulp;</li>
  <li>Integração de fontes personalizadas e variáveis/mixins reutilizáveis em SCSS;</li>
  <li>Estrutura limpa de projeto com saída em <code>dist</code> gerada pelo build do Gulp.</li>
</ul>
<h2>📦 Tecnologias Utilizadas</h2>
<ul>
  <li><strong>HTML5</strong> para estrutura;</li>
  <li><strong>SASS/SCSS</strong> para estilização e modularidade;</li>
  <li><strong>JavaScript (ES6)</strong> para lógica do FAQ e do cabeçalho;</li>
  <li><strong>Gulp</strong> como task runner;</li>
  <li>Plugins Gulp: <code>gulp-sass</code>, <code>gulp-uglify</code>, <code>gulp-imagemin</code>, <code>gulp-watch</code>.</li>
</ul>
<h2>⚙️ Scripts</h2>
<pre>
npm run watch   # Inicia o modo de desenvolvimento com observação de arquivos
npm run build   # Gera os assets otimizados em /dist
</pre>
