<h1>Streaming Landing Page</h1>
<p>
  Este README também está disponível em <a href="./README.pt-br.md">Português</a>.
</p>
<p>
  A responsive landing page inspired by <i>Puss in Boots: The Last Wish</i>, built to practice
  <strong>Gulp</strong>, <strong>SASS/SCSS</strong>, and frontend workflows.
  It demonstrates asset optimization, modular SCSS, FAQ interactivity, and dynamic header behavior.
</p>
<h2>🚀 Features</h2>
<ul>
  <li>Responsive layout built with HTML5, SCSS, and modular mixins;</li>
  <li>Interactive FAQ section with smooth open/close behavior;</li>
  <li>Dynamic header that hides and reappears based on scroll position;</li>
  <li>Optimized assets (images, styles, scripts) using Gulp plugins;</li>
  <li>Custom font integration and reusable SCSS variables/mixins;</li>
  <li>Clean project structure with <code>dist</code> output from Gulp build.</li>
</ul>
<h2>📦 Technologies Used</h2>
<ul>
  <li><strong>HTML5</strong> for structure;</li>
  <li><strong>SASS/SCSS</strong> for styling and modularity;</li>
  <li><strong>JavaScript (ES6)</strong> for FAQ and header logic;</li>
  <li><strong>Gulp</strong> as task runner;</li>
  <li>Gulp plugins: <code>gulp-sass</code>, <code>gulp-uglify</code>, <code>gulp-imagemin</code>, <code>gulp-watch</code>.</li>
</ul>
<h2>⚙️ Scripts</h2>
<pre>
npm run watch   # Start development mode with file watching
npm run build   # Build optimized assets into /dist
</pre>
